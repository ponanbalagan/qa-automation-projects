# QA Automation Projects

A portfolio of test automation projects covering web UI testing, API testing and
QA documentation, built with Java, Python, Selenium, Playwright, TestNG and pytest.

## Projects
| Folder | Description | Tech | Status |
|---|---|---|---|
| selenium-java-framework | Web UI test framework with Page Object Model and reports | Java, Selenium, TestNG, Maven | Planned |
| playwright-python-framework | Web UI tests with Page Object Model | Python, Playwright, pytest | Planned |
| api-testing | REST API tests and Postman collections | Postman, RestAssured | Planned |
| test-documentation | Test plan, test cases and bug reports | Markdown | Planned |

## How the repository is organized
- One self-contained folder per project, each with its own README.md
- Java projects use Maven (pom.xml), Python projects use requirements.txt
- Commit messages follow the format type: short description (feat, fix, docs, chore)
